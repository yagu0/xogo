# xogo.casa

Simplified version of old vchess.club, to focus on the essential.

## Requirements (dev)

PHP + Node.js + npm.

```npm i -g nodemon```

## Usage

Initialisation (done only once):

```./initialize.sh```

Edit the parameters.js file:

```vim js/parameters.js```

Finally:

```./start.sh``` (and later, ```./stop.sh```)
